Implementation of statistical analysis made on a data set using mean,
median, maximum and minimum statistical functions. The purpose of this
project is to practice using git as well as implementing sorting
algorithm while also calculating some of the statistics functions.

---

I explicitly decided to replace the original array in sorting algorithm
to optimize the algorithm's time usage. With the same goal I never created
any additional arrays inside recursive algorithm, but navigated using indexes
instead.

---

I also decided to switch from initial idea of using merge sort to using
quick sort because I thought it would be fun. It doesn't have any other
meaning (merge sort has actually better performance in worst cases).
